> 디스코드에서 쓰는 기능: 명령어, 대화 도구, 작업, 유저 기억, 페르소나

## 디스코드 사용법 (슬래시 명령)

- **`/help`** — 처음 쓰는 사람용 안내. 주제를 고르면 자세히 (처음 시작 · 대화·기억 · 도구 · 알림·백그라운드·예약 · 내 정보·프라이버시 · 관리자). 결과는 본인에게만 보입니다.
- `@라스페치아 도움말` / `사용법` / `뭐 할 수 있어?` 만 보내도 같은 요약이 나옵니다 (Gemini 호출 없음 → 토큰 0).
- 봇을 **새 서버에 초대하면** 시스템 채널(없으면 쓸 수 있는 첫 채널)에 자기소개를 한 번 올립니다.


- 서버: `@라스페치아 안녕` 또는 봇 메시지에 답장 · DM: 그냥 말하기
- `/memory recall <질문>` — 이 서버(또는 DM)의 장기 기억 검색 (본인에게만 보임)
- `/memory save` — 이 채널에 쌓인 대화를 지금 바로 저장
- `/memory status` — 대기 버퍼·저장 현황

슬래시 명령은 처음 반영까지 최대 1시간. `.env`에 `DEV_GUILD_ID=<서버ID>`를 넣으면 그 서버엔 즉시 반영됩니다.

## 🛠️ 대화 도구 (Gemini Function Calling)

봇과 대화하다 보면 계산·날씨·검색이 필요한 순간이 있습니다. 봇이 **스스로 판단해서** 아래 도구를 호출하고, 결과를 자연스러운 말로 바꿔 답합니다. 명령어를 외울 필요 없이 그냥 말하면 됩니다.

| 도구 | 이렇게 말하면 | 동작 | 외부 서비스 |
|---|---|---|---|
| `calculate` | "1인당 18,500원 7명에 봉사료 10%면?" | 안전한 수식 계산기 (eval 미사용) | 없음 |
| `get_weather` | "내일 부산 날씨 어때? 우산 챙겨?" | 현재 날씨 + 최대 7일 예보 | Open-Meteo (무료, 키 없음) |
| `web_search` | "요즘 엔비디아 주가 어때?" | 구글 검색 결과 요약 + 출처 | Gemini Google Search 그라운딩 |
| `convert_currency` | "100달러면 원화로 얼마야?" | 환율 변환 (1시간 캐시) | open.er-api.com (무료, 키 없음) |
| `date_calc` | "크리스마스까지 며칠 남았어?" | D-day, 날짜 더하기, 요일 | 없음 |
| `get_current_time` | "뉴욕은 지금 몇 시야?" | 세계 시각 | 없음 |
| `random_pick` | "점심 메뉴 골라줘: 김치찌개, 돈까스, 쌀국수" | 고르기·주사위·동전·숫자·순서 섞기 | 없음 |
| `set_reminder` | "40분 뒤에 빨래 꺼내라고 알려줘" | 시각이 되면 그 채널에서 멘션 | 없음 (FalkorDB 에 저장) |
| `list_reminders` / `cancel_reminder` | "내 알림 뭐 있어?" / "그거 취소해" | 예약 확인·취소 | 없음 |
| `search_memory` | "내가 전에 말한 그 책 제목 뭐였지?" | 장기 기억을 다른 검색어로 재검색 | 없음 |
| `fetch_url` | "이 링크 내용 요약해줘" | 웹페이지 본문 읽기 (내부망 주소 차단, 자동 접근을 막는 사이트는 실패) | 해당 사이트 |
| `start_background_task` | "~조사해서 나중에 알려줘" | 백그라운드 작업 시작 | — |
| `schedule_task` / `list_tasks` / `cancel_task` | "매일 8시에 뉴스 요약해줘" / "내 작업 뭐 있어?" | 예약 작업 | — |

**말만 하고 끝내지 않기 (자동 이어서 하기)**
- 봇이 "살펴볼게", "찾아올게", "정리해서 보여줄게"처럼 **할 일을 말만 하고** 끝내려 하면, 보내기 전에 한 번 다시 시켜 그 자리에서 완성하게 합니다.
- 그래도 약속만 하고 끝난 답변이 나가면, **사용자가 다시 부르지 않아도** 봇이 스스로 이어서 검색·정리한 뒤 그 답변에 **후속 메시지**로 결과를 올립니다 (최대 5단계 · 2분 · 6만 토큰, 입력 중 표시).
- 할 일이 없는 인사성 약속("내일 또 얘기 들어줄게")은 후속 메시지를 보내지 않습니다. 리마인더·백그라운드 작업처럼 실제로 예약한 경우도 제외.
- 로그: `🔁 약속만 하고 끝난 답변 → 스스로 이어서 처리`, `🔁 후속 메시지 전송`

**동작 방식**
- 한 답변에서 최대 `CHAT_MAX_TOOL_STEPS`(기본 4)번까지 도구를 이어서 호출합니다 (예: 검색 → 계산).
- 도구가 실패해도 봇은 죽지 않고, 모델이 "확인이 어렵다"고 자연스럽게 답합니다.
- 리마인더는 FalkorDB 에 저장되어 **봇을 재시작해도 유지**되고, 15초 간격으로 확인해 보냅니다. 한 사람당 25개, 최대 60일 뒤까지.
- 관리 웹 **⚙ 봇 설정 → 미리보기**에서도 도구가 동작하므로 페르소나와 함께 시험해 볼 수 있습니다. (리마인더·기억 검색은 디스코드에서만)

**비용·끄기**
- 도구 정의가 매 답변 프롬프트에 약 1천 토큰 추가되고, 도구를 쓰면 Gemini 호출이 1~2회 늘어납니다.
- `web_search` 는 Google Search 그라운딩을 써서 **별도 요금/일일 무료 한도**가 있습니다 (Google AI Studio 요금 정책 참고).
- 일부만 켜기: `.env` 에 `TOOLS_ENABLED=calculate,get_weather,date_calc,random_pick,set_reminder,list_reminders,cancel_reminder`
- 전부 끄기: `TOOLS_ENABLED=none`

**도구 추가하기** — `app/tools/` 아래 아무 모듈에 `@tool(이름, 설명, 파라미터)` 로 async 함수를 등록하고 `app/tools/__init__.py` 의 `_load_modules()` 에 모듈을 추가하면 됩니다.

## 📋 백그라운드 · 예약 작업

일상 대화는 그 자리에서 바로 답하지만(도구 최대 5번), **오래 걸리는 조사**는 백그라운드로 넘깁니다. Codex·Claude Code 같은 에이전트처럼 "생각 → 검색/페이지 읽기 → 확인"을 여러 번 반복한 뒤 결과를 올립니다.

```
사용자: @라스페치아 2026년 개봉 애니 영화 조사해서 정리해 줘
봇:     작업 #b11991 으로 시작했어요! 끝나면 여기 올릴게요.
봇:     🔄 작업 #b11991 5/12단계 · web_search(…)        ← 같은 메시지가 계속 수정됨
봇:     ✅ 작업 #b11991 완료 · 10단계 · 28,684토큰 · 28초
봇:     @사용자 📄 작업 #b11991 결과 — …                  ← 원래 메시지에 답장
```

**맡기는 방법**
- 말로: "조사해서 알려줘", "자세히 찾아서 정리해 줘" → 봇이 판단해 백그라운드로 넘김
- 명령으로: `/task start <할 일>` · `/task list` · `/task cancel <번호>`
- 예약: "매일 아침 8시에 서울 날씨랑 주요 뉴스 3개 요약해줘", "매주 금요일 18시에 주말 영화 추천해줘", "내일 9시에 ~해줘"
- 단순한 알림 문구("3시에 회의 알려줘")는 작업이 아니라 리마인더로 처리됩니다(토큰 0).

**어디서 돌아가나** — 작업 실행 루프·웹페이지 읽기·텍스트 정리는 **이 노트북의 봇 컨테이너**에서 돌고, 판단(생각)은 Gemini `TASK_MODEL`(기본 flash-lite)이 합니다. 작업 기록은 FalkorDB에 저장되어 관리 웹 **📋 작업** 화면에서 진행 상황·결과·토큰을 보고 취소할 수 있습니다.

**조사 한도** (`.env`)

| 한도 | 기본값 | 넘으면 |
|---|---|---|
| `TASK_MAX_STEPS` 작업당 단계 | 12 | 지금까지 모은 정보로 보고서 작성 ("한도로 마무리" 표시) |
| `TASK_MAX_SECONDS` 작업당 시간 | 600초 | 〃 |
| `TASK_MAX_TOKENS` 작업당 토큰 | 150,000 (약 60원) | 〃 |
| `TASK_MAX_CONCURRENT` 동시 실행 | 1 | 대기열에서 순서대로 |
| 사용자별 동시 진행 | 2 | 새 작업 거절 |
| `TASK_DAILY_LIMIT` 사용자별 하루 | 10 | 다음 날까지 거절 |
| `TASK_MAX_SCHEDULED` 사용자별 예약 | 5 | 새 예약 거절 |

실측: 영화 목록 조사 1건 = 10단계 · 28,684토큰(약 12원) · 28초.

**재시작 시** — 대기 중이던 작업은 다시 실행, 실행 중이던 작업은 "재시작으로 중단"을 알리고 실패 처리(중복 비용 방지), 예약은 그대로 유지(꺼져 있는 동안 지나간 1회성 예약은 실패 처리).

**끄기** — `TASKS_ENABLED=false`

## 👤 유저별 기억

서버 기억(`guild-…`)은 그대로 두고, **사람마다 개인 기억 공간(`user-<디스코드ID>`)** 이 따로 쌓입니다.

- 어느 서버에서든 봇과 나눈 대화가 그 사람의 개인 공간에도 저장됩니다. DM은 개인 공간에만 저장됩니다.
- 답할 때 **서버 기억 + 말하는 사람의 개인 기억**을 함께 떠올립니다. (A서버에서 말한 취미를 B서버에서도 기억)
- 관리 웹 왼쪽 목록에 `👤 이름` (유저 배지)으로 나오고, 그래프 탭에서 **그 사람 중심의 관계도**를 볼 수 있습니다.
- 이전 버전의 DM 기억(`dm-…`)은 지우지 않았고, DM에서 답할 때 계속 함께 검색합니다. 관리 웹에는 `DM(이전)`으로 표시됩니다.

**사용자 본인 관리** — `/memory me` (나에 대한 기억 보기, 본인에게만 표시) · `/memory forget_me confirm:삭제` (내 개인 기억 전체 삭제, 서버 기억은 유지)

**프라이버시** — 개인 기억은 다른 서버에서도 떠올릴 수 있으므로, 봇은 여러 사람이 보는 서버에서 건강·연애·주소·금전 같은 민감한 개인 기억을 먼저 꺼내지 않도록 지시되어 있습니다. 서버 멤버들에게 이 기능을 알려 주세요.

**모드와 비용** — `.env` 의 `USER_MEMORY_MODE` (채팅 답변 비용은 모드와 무관, **기억 저장** 비용만 달라짐)

| 모드 | 서버 대화를 개인 공간에 저장하는 방식 | 기억 저장 비용 (서버 기억만 = 1) | 추천 |
|---|---|---|---|
| `full` (기본) | 서버와 같은 방식(8마디/90초, 봇 답변 600자까지) | 약 2배 | 여러 서버·DM에서 같은 사람이 자주 쓸 때 |
| `lite` | 16마디/10분 단위로 크게 묶고, 봇 답변은 앞 120자만 | 약 1.3~1.5배 (추정) | 비용을 아끼면서 서버 간 기억은 유지 |
| `off` | 저장 안 함 (DM은 개인 공간에 계속 저장) | 1배 | 주로 한 서버에서만 쓸 때 |

- 같은 서버 안에서는 서버 기억에도 그 사람에 대한 사실이 남으므로, 개인 기억의 차이는 **서버를 넘나들 때·DM과 서버를 오갈 때·사람이 많은 서버에서 "나"에 대한 질문을 할 때** 크게 납니다.
- `lite` 묶음 크기·봇 답변 길이는 `USER_LITE_BATCH_MESSAGES`, `USER_LITE_IDLE_SECONDS`, `USER_LITE_BOT_CHARS` 로 조정. 예전 설정 `USER_MEMORY=false` 는 `off` 로 인식합니다.
- 실제 비용 차이는 `/usage` 의 "🧠 기억 저장(추출)" 항목으로 확인하세요.

## 🎭 페르소나 바꾸기

봇의 이름·말투·성격은 코드를 건드리지 않고 바꿀 수 있습니다. **봇 재시작도 필요 없습니다** (몇 초 안에 다음 답변부터 반영).

**방법 1 — 관리 웹 (가장 쉬움)**
1. 관리 웹 오른쪽 위 **⚙ 봇 설정**
2. 이름·페르소나 입력 (또는 *다정한 친구 / 츤데레 / 집사 / 공부 멘토* 예시 불러오기)
3. 오른쪽 **미리보기**에 메시지를 보내 말투 확인 → **저장**

**방법 2 — 파일 (`config/persona.md`)**
- 메모장으로 열어 고치고 저장하면 끝. `#`으로 시작하는 줄은 메모로 무시됩니다.
- git에 함께 저장되므로 페르소나 변경 이력을 남기고 싶을 때 좋습니다.

**적용 우선순위**: 관리 웹에서 저장한 값 → `config/persona.md` → `.env`의 `BOT_NAME`/`BOT_PERSONA` → 기본값.
관리 웹에서 **파일 값으로 되돌리기**를 누르면 웹 값이 지워지고 `config/persona.md`가 다시 쓰입니다.

**잘 쓰는 팁**
- "너는 ~다"로 정체성 → 말투 → 성격 → 금지 규칙 순서로 짧게 쓰세요.
- 너무 길면(수천 자) 매 답변마다 토큰이 늘어납니다. 보통 300~800자면 충분합니다.
- 기억 활용 방식(관련 있을 때만 자연스럽게 꺼내기, 지어내지 않기)과 답변 길이 규칙은 코드에 이미 들어 있어서 페르소나에 쓰지 않아도 됩니다.
- 디스코드에 **표시되는** 이름/프로필 사진은 Developer Portal 또는 서버 닉네임에서 따로 바꿔야 합니다.
