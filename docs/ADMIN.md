## 🛡️ 관리 체계 (Admin)

### 구성 요소와 권한

| 구성 요소 | 주소 | 인증 | 할 수 있는 일 | 누구용 |
|---|---|---|---|---|
| **관리 웹** (admin) | `http://<PC IP>:8090` | HTTP Basic (`ADMIN_USER` / `ADMIN_PASSWORD`) | 기억 조회·수정·만료·삭제, 공간 삭제, 봇 이름·페르소나 변경, 저장 로그 | 봇 관리자 |
| **디스코드 슬래시 명령** | 디스코드 | 디스코드 계정 | `/memory recall·save·status` (자기 서버/DM 범위만, 결과는 본인에게만 보임) | 모든 사용자 |
| **FalkorDB Browser** | `http://<PC IP>:3000` | **없음** ⚠️ | 원본 그래프 직접 조회·Cypher 실행 (수정·삭제도 가능) | 개발/디버깅 |
| **docker / .env** | 이 PC | PC 로그인 | 토큰·키·비밀번호, 시작/중지, 백업 | PC 주인 |

- 관리 웹은 **하나의 관리자 계정**만 있습니다(역할 구분 없음). 비밀번호를 아는 사람은 모든 서버의 기억을 보고 지울 수 있으니 공유에 주의하세요.
- `ADMIN_PASSWORD`를 비워 두면 **인증 없이** 열리고, 화면 상단에 노란 경고가 뜹니다.
- 디스코드 사용자는 **자기 서버(또는 자기 DM)의 기억만** 검색할 수 있습니다. 다른 서버의 기억은 그래프 자체가 분리되어 있어 접근할 수 없습니다.
- FalkorDB Browser는 인증이 없으므로, 필요 없다면 `docker-compose.yml`에서 `3000` 포트 줄을 주석 처리하세요.

### 관리 웹 화면별 기능

| 화면 | 기능 |
|---|---|
| 왼쪽 **기억 공간** | 서버(`guild-…`)·DM(`dm-…`) 목록, 엔티티/사실 수. 아래쪽에 봇 상태(누적 저장, 실패, 대기 버퍼) |
| 상단 **상태 표시** | 🟢 봇 온라인 · 대기 중인 대화 수 · 저장 중 작업 수 (90초 이상 보고 없으면 🔴 오프라인) |
| **⚙ 봇 설정** | 봇 이름·페르소나 편집, 예시 불러오기, 저장 전 **미리보기**, 파일 값으로 되돌리기 |
| **그래프** | 엔티티-관계 네트워크. 노드 크기 = 연결 수, 빨간 점선 = 만료된 사실. 노드 클릭 → 상세 패널 |
| 상세 패널 | 엔티티 요약 수정, 연결된 사실(수정·만료·삭제), 이 엔티티가 언급된 원본 대화, 엔티티 삭제 |
| **사실** | 모든 관계(사실) 목록·필터. 문장 수정 시 임베딩 자동 재계산 |
| **에피소드** | 한 번에 저장된 원본 대화 묶음. 삭제하면 그 대화에서만 생긴 엔티티/사실도 정리 |
| **의미 검색** | 봇이 답변할 때 쓰는 것과 같은 검색(BM25+임베딩)으로 "봇이 무엇을 떠올릴지" 확인 |
| **저장 로그** | 저장 성공(✅ 엔티티·관계 수, 소요 시간)과 실패(⚠️ 오류 내용) 기록 |
| **공간 삭제** | 탭 줄 오른쪽. 공간 ID를 직접 입력해야 실행되는 **영구 삭제** |

### 관리 원칙: 만료 vs 삭제

| 상황 | 권장 동작 | 이유 |
|---|---|---|
| 예전엔 맞았지만 지금은 아님 (이사, 퇴사, 헤어짐) | **만료** | 봇이 "과거 사실"로 알고 시간 맥락을 유지 |
| 사실 문장이 조금 틀림 | **수정** | 임베딩까지 다시 계산되어 검색에 반영 |
| 애초에 잘못 추출됨 / 사적인 정보라 지워야 함 | **삭제** | 완전히 제거 (되돌릴 수 없음) |
| 특정 대화 전체를 잊게 하고 싶음 | 에피소드 **삭제** | 그 대화에서만 생긴 엔티티·사실까지 함께 정리 |
| 서버를 떠났거나 처음부터 다시 | **공간 삭제** | 그 서버의 그래프 전체 삭제 |

삭제는 되돌릴 수 없으니, 중요한 정리 전에는 [백업](SETUP.md#백업--복원)을 먼저 하세요.

### 다른 기기에서 접속 (같은 와이파이 · Tailscale)

컨테이너는 이미 모든 네트워크 주소(`0.0.0.0:8090`)로 열려 있습니다. Windows 방화벽만 허용하면 됩니다. **관리자 PowerShell**에서 한 번만:

```powershell
Set-NetConnectionProfile -InterfaceAlias "Wi-Fi" -NetworkCategory Private
```

```powershell
Set-NetFirewallRule -DisplayName "Docker Desktop Backend" -Action Allow -Profile Private
```

- 첫 줄: 집 와이파이를 '개인 네트워크'로 지정 (공용 와이파이에서는 계속 차단됨)
- 둘째 줄: Docker 설치 때 만들어진 **차단** 규칙을 개인 네트워크에서만 **허용**으로 변경
- 접속: 같은 와이파이의 휴대폰/PC에서 `http://<이 PC의 IP>:8090` (IP 확인: `ipconfig` → Wi-Fi의 IPv4 주소)
- Tailscale을 쓰면 밖에서도 `http://<Tailscale IP>:8090` 으로 접속 가능
- 공유기가 IP를 바꿀 수 있으니, 공유기 설정에서 이 PC에 **고정 IP(DHCP 예약)** 를 지정해 두면 편합니다.
- **인터넷(공유기 포트포워딩)에 공개하는 것은 권장하지 않습니다.** 밖에서 쓰려면 Tailscale을 쓰세요.

## 🌐 관리 웹 외부 접속

| 방법 | 누가 접속 가능 | 주소 | 준비물 |
|---|---|---|---|
| 같은 와이파이 | 집 안 기기 | `http://<PC IP>:8090` | 방화벽 설정 ([위](#다른-기기에서-접속-같은-와이파이--tailscale)) |
| Tailscale (사설망) | 내 Tailscale 기기만 | `http://<Tailscale IP>:8090` | 각 기기에 Tailscale 앱 + 같은 계정 |
| **Tailscale Funnel** (공개) | 인터넷의 누구나 *(비밀번호 필요)* | `https://<PC이름>.<tailnet>.ts.net` | Tailscale 만 있으면 됨, 도메인 불필요 |
| **Cloudflare Tunnel** (공개) | 〃 | 내 도메인 또는 임시 `*.trycloudflare.com` | Cloudflare 계정 (임시 주소는 불필요) |

### Tailscale Funnel (이 PC에 적용된 방식)

```powershell
tailscale funnel --bg 8090          # 켜기 (PC 재부팅 후에도 유지)
tailscale funnel status             # 주소 확인
tailscale funnel --https=443 off    # 끄기
```

- 처음 켤 때 tailnet 에서 Funnel 이 꺼져 있으면 링크가 나옵니다 → 브라우저로 열어 허용.
- **PC 와 Tailscale 이 켜져 있어야** 접속됩니다. 관리 웹(8090)만 공개되고 FalkorDB Browser(3000)는 공개되지 않습니다.

### Cloudflare Tunnel (Tailscale 이 없을 때)

```powershell
docker compose --profile quicktunnel up -d                      # 임시 주소 (계정 불필요, 재시작마다 바뀜)
docker compose logs quicktunnel | findstr trycloudflare          # 주소 확인
```

고정 주소: Cloudflare 대시보드 → Zero Trust → Networks → Tunnels 에서 터널을 만들고 Public hostname 을 `http://admin:8000` 으로 지정 → 토큰을 `.env` 의 `CLOUDFLARE_TUNNEL_TOKEN` 에 넣고 `docker compose --profile tunnel up -d`.
(Cloudflare Access 로 이메일 로그인까지 걸면 한층 안전합니다.)

### 공개할 때의 보안 장치 (자동 적용)

- **비밀번호 필수**: 터널로 들어온 요청인데 `ADMIN_PASSWORD` 가 비어 있으면 무조건 403 거부
- **로그인 잠금**: 같은 IP 가 10분에 10번 틀리면 15분 잠금, 전체 10분에 50번 틀리면 10분 잠금 (로그에 `관리 웹 로그인 실패 … (터널)` 기록)
- **보안 헤더**: 다른 사이트에 끼워 넣기 금지(클릭재킹 방지), 콘텐츠 보안 정책(CSP), API 응답 캐시 금지
- HTTPS 는 Funnel/Cloudflare 가 처리 (비밀번호가 암호화되어 전송)

**사용자가 할 일**: `ADMIN_PASSWORD` 를 **길고 추측 불가능하게**(16자 이상) 유지하고, 공유했던 사람이 빠지면 바꾸세요. 관리 웹에서는 기억 삭제도 가능하므로 비밀번호 = 모든 기억에 대한 권한입니다. 필요 없을 때는 Funnel 을 꺼 두는 게 가장 안전합니다.

## 📊 API 사용량 · 비용

Gemini API 는 API 키로 사용량·청구액을 조회할 수 없어서, **봇이 모든 Gemini 호출의 토큰을 직접 세어** FalkorDB에 일별로 기록하고 단가를 곱해 추정 비용을 보여 줍니다.

- 디스코드: `/usage` (기본 이번 달) · `/usage period:오늘|최근 7일|이번 달|최근 30일` — 결과는 본인에게만 보임
  - 서버에서는 **서버 관리 권한**이 있는 사람에게만 명령이 보이고(디스코드 서버 설정 → 연동에서 바꿀 수 있음), DM에서는 봇 주인만 쓸 수 있습니다.
- 관리 웹: 상단 **📊 사용량** — 기간별 합계, 항목별, 일별 추정 비용 막대

| 항목 | 무엇이 들어가나 | 계산 |
|---|---|---|
| 💬 채팅 답변 | 멘션/DM 답변, 관리 웹 미리보기 | 입력·출력(사고 포함)·캐시 토큰 × 단가 |
| 🧠 기억 저장 | Graphiti 엔티티·관계 추출 | 〃 |
| 📋 백그라운드 작업 | 조사 에이전트 | 〃 |
| 🔎 웹 검색 | 검색 요약 호출 + **그라운딩 횟수** | 토큰 비용 + 월 무료 한도(5,000회) 초과분 × $14/1,000회 |
| 🧬 임베딩 | 기억 저장·검색용 벡터 | 응답에 토큰 수가 없어 글자 수로 근사 |

**주의**
- **추정치**입니다. 무료 티어를 쓰면 실제 청구는 0원이고, 유료라도 단가 변경·반올림 때문에 차이가 날 수 있습니다. 정확한 금액은 [Google AI Studio](https://aistudio.google.com) 의 사용량/결제 화면이 기준입니다.
- 단가는 `.env` 의 `PRICE_*` 로 바꿀 수 있습니다 (기본: flash-lite 입력 $0.30 · 출력 $2.50 / 100만 토큰).
- 기록은 이 기능을 넣은 시점부터 쌓입니다. 리랭커(거의 쓰이지 않음)는 집계에서 빠집니다.
